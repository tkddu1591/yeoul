# 여울 v0.1.0 공개 베타

브랜치와 여러 워크트리를 한곳에서 편하게 살펴보고, 변경 검토부터 커밋과 통합까지 이어가는 macOS Git GUI입니다.

## 주요 기능

- 변경 파일, hunk, 줄 단위 스테이지·언스테이지와 diff
- 브랜치와 워크트리 조회, 생성, 전환, 비교, 제거
- 커밋 히스토리, 충돌 해결, 스태시, pull·push, GitHub PR
- 저장소별 터미널과 외부 변경 자동 감지
- Apple Silicon과 Intel Mac을 모두 지원하는 Universal 앱
- 새 버전 감지, SHA-512 검증 및 DMG 열기

## 설치

1. `Yeoul-0.1.0-universal.dmg`를 다운로드합니다.
2. DMG를 열고 여울을 응용 프로그램 폴더로 옮깁니다.
3. 첫 실행에서 Gatekeeper가 막으면 Finder에서 여울을 우클릭한 뒤 `열기`를 선택합니다.

## 알아둘 점

- 현재 Apple Developer ID 서명·공증이 없는 공개 베타입니다.
- 업데이트는 DMG 다운로드·검증·열기까지 자동이며 앱 교체는 수동입니다.
- 중요한 저장소는 원격에 백업한 뒤 사용하는 것을 권장합니다.
