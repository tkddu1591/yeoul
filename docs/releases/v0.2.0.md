# 여울 v0.2.0 공개 베타

여러 저장소와 워크트리를 한 화면에서 함께 살펴보고, 흩어진 변경을 저장소별로 안전하게 올리고 내릴 수 있도록 멀티레포 작업 흐름을 확장했습니다.

## 이번 버전의 변화

- 선택한 상위 폴더 아래의 여러 Git 저장소와 워크트리를 통합 트리로 표시
- 저장소별 변경 파일과 커밋 히스토리를 한 화면에서 빠르게 전환
- 여러 저장소의 변경을 선택해 한 번에 스테이지·언스테이지
- 워크트리와 일반 저장소를 구분하는 배지와 현재 작업 위치 표시
- 저장소 선택 화면과 헤더의 정보 밀도·간격·반응형 동작 개선
- 일반, 외형, 원격 설정을 분리하고 테마·터미널 색상 체계 개선

## 기존 주요 기능

- 변경 파일, hunk, 줄 단위 스테이지·언스테이지와 diff
- 브랜치와 워크트리 조회, 생성, 전환, 비교, 제거
- 커밋 히스토리, 충돌 해결, 스태시, pull·push, GitHub PR
- 저장소별 터미널과 외부 변경 자동 감지
- Apple Silicon과 Intel Mac을 모두 지원하는 Universal 앱
- 새 버전 감지, SHA-512 검증 및 DMG 열기

## 설치

1. `Yeoul-0.2.0-universal.dmg`를 다운로드합니다.
2. DMG를 열고 여울을 응용 프로그램 폴더로 옮깁니다.
3. 첫 실행에서 Gatekeeper가 막으면 Finder에서 여울을 우클릭한 뒤 `열기`를 선택합니다.

기존 v0.1.0 사용자는 앱의 업데이트 안내에서 새 DMG를 내려받아 검증한 뒤, 응용 프로그램 폴더의 여울을 교체할 수 있습니다.

## 알아둘 점

- 현재 Apple Developer ID 서명·공증이 없는 공개 베타입니다.
- 업데이트는 DMG 다운로드·검증·열기까지 자동이며 앱 교체는 수동입니다.
- 중요한 저장소는 원격에 백업한 뒤 사용하는 것을 권장합니다.
