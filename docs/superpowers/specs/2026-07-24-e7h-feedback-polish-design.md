# E7h — 피드백 폴리시 7건 설계 (알림 비가림·파일 트리·워크트리 동시성·터미널 그룹·삭제 사유·⌘F·신호등)

2026-07-24 사용자 피드백 7건(E7g 병합 직후 dev 실사용) 확정본. 선택지 4건은 전부 추천안으로 확정: ④ 워크트리별 탭 묶음, ⑤ 사유+동반 삭제 제안, ⑥ 4개 패널 전부, ⑦ 신호등을 헤더 중앙에.

## ① 알림 비가림 — 오버레이 스택을 좌측 열 오른쪽부터

- 현상: 배너(에러·알림·머지 바) 콘텐츠를 `padding-left: 210px`(E7a 탭 2개 시절 실측)로 밀어 탭바(z-41)를 피하는데, E7c에서 워크트리 탭이 추가돼 탭바가 그 폭을 넘어 알림을 가림.
- 설계: 하드코딩 패딩 제거. **`app__top-stack`의 `left`를 좌측 열 폭(+좌측 패딩·gap)만큼 inline style로 지정** — App이 leftWidth 상태(리사이저)를 이미 알고 있다. 스택이 탭바 구역과 아예 겹치지 않으므로 배너의 `padding-left: 210px` 세트 삭제, 기본 패딩 복원.
- 리사이즈 중에도 left가 따라간다(같은 상태에서 파생). 탭바 z-41은 유지(머지 바 클릭 차폐 방지 — E7a 실측 사유는 여전).
- 배너 배경이 전체 폭이 아니게 되는 시각 변화는 의도된 것(알림은 콘텐츠 구역의 것) — 그림자 유지.

## ② 커밋 상세 파일 목록 depth 트리

- `file-tree.ts` 순수 함수 신설(브랜치 트리와 같은 세그먼트 방식, 파일 대상): `buildFileTree(files)`(경로 `/` 분해, 입력 순서 보존, 폴더 count=하위 파일 수) · `flattenFileTree(nodes, collapsedSet)`(depth 행 목록) · 검색 평면화는 ⑥의 필터가 담당(검색어 있으면 트리 대신 평면 매치 — E7g 규칙).
- CommitDetailPanel 파일 목록을 트리 렌더로 교체: 폴더 행(▸/▾ + 이름 + count, 클릭=접기 토글) + 파일 행 들여쓰기(단계당 고정 인덴트). 접기 상태는 컴포넌트 로컬(커밋 전환 시 리셋 — 커밋마다 파일 구성이 다르다). 기본 펼침.
- 무변: 파일 행의 kind 글리프·색, rename `a → b` 툴팁, 클릭 diff, 우클릭("이 파일만 지금 코드에 적용"·"지금 코드와 비교"), testid(`commit-file-<path>`), 보관함 미리보기(같은 컴포넌트 재사용이므로 자동 적용).
- 좌측 변경 목록은 트리화하지 않는다(피드백 범위 밖 — 체크박스 스테이징 UI와 얽혀 별건).

## ③ 워크트리 전환 동시성

- 현상: "앱 전체 전환" 모드의 select가 `setActiveWorktree`(터미널 대상, 동기) 후 `openWorktree`(비동기 스냅샷)라 터미널이 먼저 바뀌고 앱이 나중에 바뀜.
- 설계: switch-app 모드에서는 **`openWorktree`가 성공한 뒤에** `setActiveWorktree`(+도크 라벨) 반영 — 한 프레임에 같이 바뀐 것으로 보인다. 실패(에러) 시 터미널 대상도 이전 그대로.
- "터미널만" 모드·우클릭 "여기서 터미널 열기"는 무변(즉시 전환이 맞는 동작).

## ④ 워크트리별 터미널 탭 묶음

- 세션에 **그룹 키** 부여: 그 터미널이 열릴 때의 워크트리 경로(`cwd` 지정 없으면 본체 repoPath). use-terminal-sessions가 tab에 `groupKey` 동봉.
- 도크 탭바는 **현재 그룹(activeWorktree?.cwd ?? repoPath)의 탭만 표시**. 다른 그룹 탭은 DOM·pty 모두 유지(백그라운드) — 돌아오면 다시 보인다.
- 그룹별 마지막 활성 탭 기억(`Map<groupKey, sessionId>`). 그룹 전환 시: 그 그룹에 탭이 있으면 기억한 활성 탭 복원, 없으면 **자동으로 1개 생성**(해당 cwd).
- 탭 라벨 번호는 그룹 내 순번. ＋ 버튼은 현재 그룹 cwd로 생성. 상한 8은 전체 세션 기준 유지(초과 시 기존 에러 안내).
- 워크트리 지우기 성공 시 그 그룹 세션 전부 close(프로세스 정리). 본체 그룹은 저장소 전환(openRepository) 시 기존 동작(전체 정리) 유지.
- E2E: 그룹 전환 시 탭 숨김/복원·자동 생성·지우기 정리.

## ⑤ 브랜치 삭제 사유 + 동반 삭제 제안

- 엔진 `branches.remove`: `used by worktree` stderr에서 **워크트리 경로를 파싱**해 구조화 반환 — `RemoveBranchResult`에 `usedByWorktree: string | null` 추가(`removed:false`). 경로 파싱 실패 시 null 경로로도 같은 분기(문구만 일반형). git 버전별 stderr 문구(`used by worktree at '…'` 등)는 플랜 실측.
- 현재 HEAD 브랜치(본체에서 체크아웃 중) 거부는 기존 메시지 유지 — stderr가 worktree 문구와 겹치면 경로가 본체(repoPath)인지로 구분(플랜 실측).
- UI(BranchesPanel 삭제 흐름): `usedByWorktree` 반환 시 확인창 — "이 실험 공간은 워크트리 ○○(폴더명)가 펼쳐 쓰는 중이에요. 워크트리도 같이 지우고 실험 공간을 지울까요?" → 승인 시 `worktrees.remove(path, force:false)` → needsForce면 기존 2단 미저장 경고 재사용 → 워크트리 제거 성공 후 `branches.remove` 재시도(원래 force 값 유지 — 미병합 needsForce 흐름은 그 다음에 평소대로).
- 취소하면 아무 것도 하지 않음.

## ⑥ ⌘F 패널 검색 (4곳)

- 공통 `FindBar` 컴포넌트: 패널 우상단 오버레이(작은 입력 + N/M 카운터 + ↑/↓ + ✕), ESC·✕ 닫기(닫으면 하이라이트/필터 해제), 입력 즉시 반영. 열릴 때 자동 포커스.
- 발동: 전역 ⌘F(⌃F)를 App에서 가로채 **마우스가 올라가 있는 패널**(elementFromPoint→`data-find-scope` 조상)에 열기, 없으면 중앙 diff. 터미널에 포커스가 있으면 가로채지 않는다(쉘 자체 검색 존중). 이미 열려 있으면 그 패널 입력 재포커스.
- 패널별 동작:
  - **히스토리(저장된 역사)**: 커밋 메시지·해시(접두) 매치 → **점프+하이라이트**(필터 아님 — 그래프 맥락 유지). 가상 목록이라 매치 인덱스로 스크롤 점프, 매치 행 하이라이트, Enter/↓=다음·⇧Enter/↑=이전(순환).
  - **diff(변경 내용)**: 행 텍스트 매치 → **점프+하이라이트**(가상 행 점프·행 내 매치 부분 마크). 좌우 나란히 양쪽 모두 대상.
  - **커밋 상세 파일 목록**: **필터** — 트리 대신 평면 매치(경로 전체 표시, E7g 검색 규칙). 검색 해제 시 트리·접기 상태 복원.
  - **좌측 변경 목록('지금 바뀐 것'·'저장 예정')**: **필터** — 경로 매치 행만. 체크박스·버튼 동작은 필터된 행에서 평소대로(전체 일괄 동작은 필터와 무관하게 전체 대상 유지 — 혼동 방지 문구 불요, 기존 semantics 유지).
- 매치는 대소문자 무시 부분 문자열(정규식 아님). 0건이면 "0/0"과 흐린 입력 테두리.
- E2E: 4패널 각 1건(열기→매치 카운트→점프/필터→ESC 복원) + hover 대상 선택 1건.

## ⑦ 신호등 헤더 중앙 정렬

- `titleBarStyle: 'hiddenInset'` → **`'hidden'` + `trafficLightPosition: { x, y }`** (macOS만). y는 헤더 실높이 기준 세로 중앙(실측으로 좌표 확정 — 헤더 높이는 padding `--space-3`×2+콘텐츠), x는 기존 여백 관례(≈20).
- 전체화면 신호등 숨김 push(E7f `window:full-screen`)·헤더 드래그·no-drag `:is()`·`body.is-fullscreen` 패딩 접기 전부 무변. 숨김 창 캡처 공존은 E7f 실측 전제 유지(hidden도 동일 계열 — 플랜에서 스크린샷 관례로 재확인).
- 시각 확인: 컨트롤러 캡처 불가(화면 기록 권한) — 사용자 실기동 확인 몫, 스크린샷은 창 내부만.
