# E9 — 커밋 컴포저 + 모서리·테두리 규칙 정리 설계

2026-07-28 사용자 피드백: "커밋 버튼 아직 슬롭버튼인데?? 보더 라운디드나 보더나 위치나 레이아웃이나 전부다". E8 Task 4가 전폭 슬래브·문장형 라벨은 없앴지만 버튼 자체의 **비례·소속·채도**는 그대로였다. 사용자 선택: **B 컴포저** + **모서리·테두리 규칙 전역 정리**.

## 실측 배경

확대 검수(1440×900 다크)에서 나온 신호:

- 버튼 실측 **51.6 × 30px**에 `border-radius: var(--radius-md)` = **9px**. 모서리가 높이의 30%라 버튼이 아니라 **둥근 덩어리**로 읽힌다. 원인은 `padding: 7px 14px`에 2글자 라벨.
- 다크 `--color-accent: #7c97fb`(연보라)가 좌측 열에서 **유일한 큰 색 면적**이다. 나머지는 전부 무채색 + 파일 상태 글리프 1개.
- 버튼이 textarea 아래 자기 줄에 혼자 떠 있다. 정렬 기준이 없어 "붙어 있지 않다"는 인상이 모서리·색을 더 도드라지게 한다.
- 130px 세로 안에 선 처리가 3종: 섹션 `border-top` + textarea `1px solid --color-border-strong` + 버튼 테두리 자리.

모서리 토큰 사용 분포(전수):

| 값 | 횟수 | 비고 |
| --- | --- | --- |
| `--radius-sm` (6px) | 24 | 사실상의 기본값 |
| `999px` | 7 | 알약(배지·ref 칩) |
| `--radius-md` (9px) | 4 | 버튼·입력 — **블롭의 원인** |
| `--radius-lg` (14px) | 3 | 패널·다이얼로그 |
| **raw `6px`** | 3 | `--radius-sm`과 **값이 같은 중복** |
| raw `10px`·`8px`·`5px`·`3px` | 각 1 | 토큰 우회 |

즉 토큰이 3단인데 실사용은 **7가지 값**으로 흩어져 있다. 하드코딩 hex 테두리는 `tokens.css`의 토큰 정의부뿐이라 **테마 대응은 정상**(문제 아님).

## ① 커밋 컴포저 (B안)

textarea와 액션 줄을 **하나의 테두리 상자**로 묶는다. 버튼이 상자에 소속되면 떠 있는 인상과 테두리 중첩이 동시에 사라진다.

```
커밋 메시지
┌────────────────────────────────┐
│ 비워 두면: a.txt 수정            │
│                                │
├────────────────────────────────┤
│ 사유 또는 대상            [커밋 ⌘↵]│
└────────────────────────────────┘
```

- **상자**: `--radius-control`(6px) 1겹. 안쪽 textarea는 테두리 없음(`border: none`), 액션 줄과는 `border-top: 1px solid var(--color-border)`로만 나눈다. 상자 바깥 `.commit-form`의 `border-top`은 유지(좌측 열 하단 영역 구분).
- **포커스**: 링을 textarea가 아니라 **상자**가 받는다(`:focus-within`). 얇은 1px 강조 테두리 유지 — 포커스가 상자 전체로 옮겨가면서 "이 상자가 하나"라는 사실이 강화된다.
- **버튼**: 채도를 낮춘 강조 — 채운 배경을 `--color-accent`(연보라 원색) 대신 **`--color-accent-soft`**(신설: 라이트 `#e6ebfd`/다크 `#2f3a52`)에 `--color-accent-strong` 글자색. 모서리 `--radius-control`. 크기는 `size="sm"` 계열(`padding: 5px 12px`)로 낮춰 액션 줄 안에 앉는다.
- **`⌘↵` 힌트**: 버튼 라벨 오른쪽에 흐린 작은 글자. **키 바인딩도 실제로 동작해야 한다** — 지금은 textarea에서 Enter가 줄바꿈일 뿐 제출 경로가 없다. `⌘/Ctrl + Enter` keydown으로 제출을 건다(IME 조합 중이면 무시 — `isComposing` 가드, E1a PromptDialog 선례).
- **왼쪽 슬롯**: E8의 사유 문구(`스테이지에 올린 파일이 없어요` 등)를 그대로 여기에 둔다. 사유가 없을 때는 빈 문자열이 아니라 **대상 요약**(`1개 파일`)을 낸다 — 빈 span이 높이 0이 되는 E8 Task 4의 함정을 구조적으로 없애고, 줄이 항상 무언가를 말한다.

## ② 모서리 규칙 — 의미 기반 3단

크기 이름(sm/md/lg)은 "무엇에 쓰는지"를 말하지 않아 드리프트를 못 막았다. **용도 이름**으로 바꾼다.

| 토큰 | 값 | 쓰는 곳 |
| --- | --- | --- |
| `--radius-control` | **6px** | 버튼·입력·행·메뉴 항목·탭·컴포저 상자 |
| `--radius-container` | **10px** | 패널·다이얼로그·팝오버·카드·터미널 도크 |
| `--radius-pill` | **999px** | 배지·ref 칩·개수 알약 |

- 기존 `--radius-sm`(6) → `--radius-control`, `--radius-lg`(14) → `--radius-container`(**14 → 10**, 패널이 덜 물렁해진다), `--radius-md`(9)는 **폐기** — 이 값이 블롭의 원인이고 컨트롤은 전부 6으로 간다.
- raw 값 7곳은 전부 토큰으로 회수: `6px`×3 → control, `10px`(히스토리 패널)·`8px`(터미널 도크) → container, `5px`(base.css)·`3px`(리사이저) → **예외로 남길지 실측 후 판단**(리사이저 3px은 4px 폭 요소라 토큰이 과하다 — 남기면 주석으로 이유를 적는다).
- **한쪽 테두리만 있는 요소는 모서리를 두지 않는다**(`border-top`만 있는 곳에 radius가 붙으면 선 끝이 뜬다).

## ③ 테두리 규칙

| 상황 | 규칙 |
| --- | --- |
| 컨테이너 경계(패널·상자·다이얼로그) | `1px solid var(--color-border)` |
| 입력 가능한 컨트롤(컴포저 상자·선택 상자) | `1px solid var(--color-border-strong)` — 누를 수 있다는 신호 |
| 고스트 버튼 | `1px solid transparent`(레이아웃 점프 방지) 유지 |
| 포커스 | `outline: none` + 강조 테두리 + `box-shadow: 0 0 0 1px` — E8에서 정한 얇은 링을 전역 규칙으로 승격 |
| 중첩 | **테두리 있는 요소 안에 테두리 있는 요소를 두지 않는다.** 나눠야 하면 한쪽 `border-top`만 쓴다 |

## 에러·엣지

| 상황 | 처리 |
| --- | --- |
| `⌘↵`가 IME 조합 중 눌림 | `event.nativeEvent.isComposing` 가드 — 한글 입력 중 오제출 차단 |
| 커밋 불가 상태에서 `⌘↵` | 무시(버튼 `disabled`와 동일 판정 재사용 — 분기 중복 금지) |
| 컴포저 안 textarea 포커스 링 | 상자가 `:focus-within`을 받으므로 textarea 자체 링은 제거 |
| 좁은 창(960px)에서 액션 줄 | 왼쪽 슬롯이 말줄임(`min-width: 0`), 버튼은 자연폭 유지 |
| `--radius-lg` 14 → 10 변경의 파급 | 패널·다이얼로그·repo-picker 3곳. 스크린샷 육안 검수 필수 |
| `--radius-md` 폐기 시 잔존 참조 | 전수 grep 0건 확인 후 토큰 삭제 |
| 라이트 테마 `--color-accent-soft` 대비 | 글자색과 4.5:1 이상 — 기존 대비 회귀 테스트(E0-1)에 케이스 추가 |

## 테스트

- **순수 단위**: 새 토큰 대비 회귀(E0-1 테스트에 `--color-accent-soft` + 글자색 쌍 추가).
- **E2E**: ① `⌘↵`로 커밋된다(IME 조합 중에는 안 된다) ② 커밋 불가 상태에서 `⌘↵`가 무시된다 ③ 컴포저 왼쪽 슬롯이 상태에 따라 사유/대상을 말한다(빈 문자열이 아니다).
- **무회귀**: E8 E2E 4건(커밋 버튼 사유·배지 부재·목록 접힘·비대칭 목록) 전건.
- **정합 게이트**: `border-radius`에 raw px가 남았는지 grep으로 확인하고, 남긴 예외는 주석 이유가 있어야 한다.
- **스크린샷**: 커밋 컴포저(비활성·활성·포커스), 패널 모서리 10px 적용 후 전체 화면 — 컨트롤러 육안 + 사용자 확인.
