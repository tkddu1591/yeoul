# E8 — 개발자 어휘 전환 + 디자인 정리 설계

2026-07-28 사용자 지시: "디자인들 좀 자세히 봐서 AI slop처럼 보이는 것들 개선해줘, 특히 저장하기 버튼" + "영문 개념은 그냥 일단 개발자용으로 다 만들어서 커밋·병합 등으로 처리해두고 쉬운 모드는 나중에 생각해보자".

**제품 방향 전환**: 지금까지 앱은 "쉬운 말"(저장하기·실험 공간·보관함)을 정체성으로 삼았다. 이제 **개발자 어휘를 기본**으로 하고, 쉬운 말은 나중에 모드로 되살린다. 그래서 문구를 하드코딩으로 갈아치우지 않고 **용어 사전 모듈**을 도입해 다음 전환 비용을 없앤다.

## 실측 배경 (프로브·grep)

- 화면 캡처로 확인한 AI-slop 신호: ① 한글 라벨 옆 영문 개념 배지(`merge`·`pull`·`push`·`PR`·`unstaged`·`staged`·`commit`·`log`)가 **화면에서 가장 채도 높은 요소** ② 저장 버튼이 전폭 채도 높은 파랑 슬래브 + `저장하기 — 1개 파일`(버튼에 em 대시·문장·중복 개수) + 2px 파란 포커스 링 ③ 동일 테두리·반경의 흰 카드 3겹 중첩, 파일 2~3개일 때 좌측에 ~500px 공백 ④ 행 액션이 `변경 취소 (0)`처럼 항상 괄호 0을 노출 ⑤ 헤더 버튼 크롬 불일치(2개만 테두리, 나머지 고스트).
- 어휘 사용량: `실험 공간` 59 · `보관함` 37 · `백업` 22 · `받아오기` 17 · `합치기` 16 · `지금 여기` 14, 한글 문자열 리터럴 약 124개. **E2E가 이 문구를 154회 단언**(`저장` 계열만 108).

## ① 용어 사전 모듈

- `apps/desktop/src/renderer/src/terms.ts` — `export const T = { … } as const`.
- **사전에 넣는 것**: 화면에 보이는 **어휘·짧은 라벨**(버튼·탭·패널 제목·배지 문구). **넣지 않는 것**: 안내 문장·확인창 본문 전체(문장까지 키로 만들면 i18n 시스템 도입 규모 — YAGNI). 문장 안의 용어는 `${T.commit}` 보간으로 참조한다.
- E2E도 같은 모듈을 import해 `getByText(T.commit)` 식으로 단언한다 — 다음 어휘 변경(쉬운 모드) 때 테스트를 고칠 필요가 없다. 문장 단언은 리터럴 유지.
- 쉬운 모드는 **후속**: 같은 형태의 두 번째 표 + 토글이면 된다(이번엔 만들지 않는다).

## ② 어휘 매핑 (확정 + 추가분)

| 지금(쉬운 말) | 바꿀 말(개발자) | 키 |
| --- | --- | --- |
| 저장하기 / 저장(명사) | **커밋** | `commit` |
| 저장 메시지 | **커밋 메시지** | `commitMessage` |
| 지금 바뀐 것 | **변경 사항** | `unstaged` |
| 저장 예정 | **스테이지** | `staged` |
| 실험 공간 | **브랜치** | `branch` |
| 보관함 | **스태시** | `stash` |
| 합치기 | **병합** | `merge` |
| 받아오기 | **가져오기** | `pull` |
| 백업 | **푸시** | `push` |
| 원격 새로고침 | **페치** | `fetch` |
| 저장된 역사 | **커밋 히스토리** | `history` |
| 지금 여기 | **현재 위치(HEAD)** | `head` |
| 겹침 / 겹침 해결 | **충돌 / 충돌 해결** | `conflict` |
| 재배치 | **리베이스** | `rebase` |
| 되돌리기 | **되돌리기(revert)** | `revert` |
| 마지막 저장 실행취소 | **마지막 커밋 취소(reset)** | `undoCommit` |
| 이 파일만 적용 | **이 파일만 체크아웃** | `checkoutFile` |
| 분리됨 | **분리 HEAD** | `detached` |
| 없어진 폴더 | **정리 대상** | `prunable` |
| 연결 없음 | **업스트림 없음** | `noUpstream` |
| 리뷰 요청 | **풀 리퀘스트** | `pullRequest` |
| 변경 내용(패널) | **Diff** | `diff` |
| 워크트리 · 태그 | (그대로) | `worktree`·`tag` |

- 영문 병기는 화면에서 빼고 **툴팁으로만** 보여준다(E7j Tooltip 재사용): 예 `병합` 버튼 툴팁 = `병합 (merge)`.
- 동사형이 필요한 자리는 사전 값에 어미를 붙여 쓴다(`${T.commit}하기`가 아니라 버튼 라벨은 그냥 `커밋`).

## ③ 커밋 폼 재설계 (지적된 "저장하기 버튼")

- **버튼**: 전폭 슬래브 → **폼 우측 정렬·자연폭**. 라벨은 `커밋` 하나(개수는 바로 위 스테이지 헤더가 이미 말한다). 색은 앱 강조색(`--color-accent`)으로 통일 — 지금의 채도 높은 파랑은 앱 어디에도 없는 톤이다.
- **비활성**: 지금은 흐린 파랑 + `0개 파일` → 회색 비활성 + 버튼 옆(또는 아래) 한 줄 사유(`스테이지에 올린 파일이 없어요`). 상태를 색이 아니라 문장으로 말한다.
- **텍스트 상자**: 2px 파란 포커스 링 → 토큰 기반 얇은 링(`--color-accent` 1px + 미세 그림자). 제안 문구 안내(`비워 두고 저장하면…`)는 **placeholder로 흡수**해 상시 회색 줄을 없앤다.
- **패널 크롬**: 카드 테두리 제거 → 좌측 열 하단의 구분선 영역. 카드 3겹 중첩이 2겹으로 준다.

## ④ 영문 개념 배지 제거

- 제거: 헤더의 `merge`·`pull`·`push`·`PR`, 패널 제목의 `unstaged`·`staged`·`commit`·`log`·`branch`·`worktree`.
- 유지: **개수 배지**(스태시 3, 변경 5), **상태 배지**(충돌·진행 중), **ref 배지**(브랜치·태그 이름), diff의 파일 상태 글리프.
- 원어가 필요한 사람은 툴팁에서 본다(②의 규칙).

## ⑤ 좌측 레이아웃 정리

- 두 목록이 세로를 반씩 고정으로 먹는 구조 → **내용 높이 기반**으로 바꾸고 남는 공간은 아래가 흡수한다. 파일이 없는 섹션은 **헤더 한 줄로 접힌다**(빈 상자 대신).
- 목록이 길면 각자 스크롤(기존 가상 스크롤 유지). 두 목록 합이 화면을 넘으면 지금처럼 반씩 나눈다.

## ⑥ 행 액션·헤더 통일

- 행 액션(`변경 취소 (0)`·`선택 올리기 (0)`·`선택 내리기 (0)`): 선택이 0이면 **괄호 숫자를 숨기고** 비활성. 회색 텍스트 링크 → 작은 고스트 버튼(파괴적 동작만 위험색).
- 헤더: 액션 버튼 크롬을 **고스트 하나로 통일**한다(헤더는 도구 모음이지 주 동작 영역이 아니다). 주 동작 강조는 각 패널이 맡는다.

## 에러·엣지

| 상황 | 처리 |
| --- | --- |
| 사전에 없는 키 참조 | 타입(`as const` + 키 유니온)으로 컴파일 타임에 막는다 |
| 문장 안 용어 보간 | `${T.branch}` 보간 — 문장 구조는 그대로 |
| E2E가 사전을 import 못 하는 경우 | 플랜 사전 실측 항목(현 tsconfig·playwright 트랜스파일 확인). 불가하면 E2E는 리터럴 유지하고 편차 기록 |
| 배지 제거로 좁아진 헤더 | E7k compact 판정은 그대로 — 필요폭이 줄어 여유만 생긴다 |
| 커밋 폼 버튼 우측 정렬 후 좁은 창 | 자연폭이라 최소창에서도 잘리지 않음(현행 전폭보다 안전) |
| 빈 섹션 접힘과 드래그 리사이즈 | 좌측 열 폭 리사이즈(E6a)와 무관 — 세로 배치만 바뀐다 |

## 테스트

- **순수 단위**: 사전 키 완전성(모든 값이 빈 문자열이 아님), 값 중복 없음(같은 라벨이 두 키에 붙으면 툴팁·단언이 모호해진다).
- **E2E**: 기존 154개 문구 단언을 사전 참조로 전환(기계적). 신규 3건 — ① 커밋 버튼이 비활성일 때 사유 문구가 보이고 스테이지 후 활성 ② 화면 어디에도 제거 대상 영문 배지(`unstaged`·`staged`·`merge`·`pull`·`push`)가 **텍스트로 존재하지 않음** ③ 변경 0개일 때 두 목록이 접혀 빈 상자가 없음.
- **스크린샷**: 커밋 폼(비활성·활성)·좌측 열·헤더 — 컨트롤러 육안 + 사용자 확인.
- **플랜 사전 실측**: E2E에서 renderer 모듈 import 가능 여부, 현재 badge 사용처 전수(`tone="git"` 목록), 좌측 두 목록의 flex 규칙 원문, 커밋 폼 컴포넌트 파일·클래스명.
