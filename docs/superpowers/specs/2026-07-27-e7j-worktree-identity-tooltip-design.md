# E7j — 워크트리 정체성 복원 + 공용 호버 툴팁 설계

2026-07-27 사용자 피드백(스크린샷 동반): 워크트리 목록에서 ① 이름이 전부 `dataworks-frontend`로 같아 어느 것인지 모르겠고 ② 경로가 `/Users/sangyeop_kim/d…`로 잘려 위치를 모르겠고 ③ 브랜치도 뒤가 잘리며 ④ 무엇에서 갈라진 워크트리인지 알 수 없다. 추가 요청: "여기서 쓰는 툴팁들 title 말고 예쁜 호버 툴팁 컴포넌트를 만들어 다 똑같이 쓰자."

**실측 배경**: codex·claude 계열 도구가 `~/.codex/worktree/<세션>/<저장소이름>` 꼴로 워크트리를 만든다. 앱은 `git worktree list --porcelain`을 그대로 읽으므로 **위치와 무관하게 목록·감시·동작은 이미 정상**이다(숨김 폴더 포함 실측 확인). 문제는 표시뿐이다. 행 이름이 경로의 마지막 조각이라 저 구조에서는 전부 같은 이름이 되고, 구분되는 조각은 경로 **가운데**(세션 폴더)에 있어 가운데 생략 압축으로는 살릴 수 없다.

## ① 워크트리 행 — 두 줄 재설계

E7g ④가 만든 한 줄 배치를 두 줄로 되돌리되, 정보 우선순위를 바꾼다.

```
➤ feature/DW-1302                              내 폴더  ❯_
  dataworks-frontend · ~/dataworks-frontend

⌂ …/dw-1051-work-review                        .claude
  dataworks-frontend · …/worktree/goofy-lalande-9418a7/

⌂ 분리됨 (a037b46)                              .codex
  dataworks-frontend · …/worktree/pivot-dimension-arrows/
```

- **1줄 = 브랜치**(주 식별자·굵게). 분리됨이면 `분리됨 (짧은해시)`. 넘치면 **앞을 생략**(`…/dw-1051-work-review`) — 뒤쪽이 구분 정보다.
- **2줄 = 폴더 이름 + 경로**(흐림). 경로는 홈을 `~`로 줄이고, 넘치면 **앞을 버리고 뒤 조각을 살린다**(`…/worktree/goofy-lalande-9418a7/`). 리프와 그 부모는 항상 보존.
- **출처 칩**(우측 상단): 홈 기준 첫 세그먼트가 dot 폴더면 그 이름(`.claude`·`.codex`), 홈 바로 아래면 `내 폴더`, 그 밖이면 최상위 폴더 이름. 특정 도구를 하드코딩하지 않고 경로에서 파생한다.
- **이름 유일화**: 리프 이름이 목록 안에서 겹치면, 구분되는 조상 세그먼트를 하나씩 앞에 붙여 유일해질 때까지 확장한다(`goofy-lalande-9418a7/dataworks-frontend`). 겹치지 않으면 짧은 이름 유지.
- `❯_`(터미널 대상)·`➤/⌂` 글리프·`없어진 폴더` 배지·흐림은 E7g·E7h 규칙 그대로.

**순수 함수로 분리**: `worktree-label.ts` — `shortenPath(path, home)`, `sourceChip(path, home)`, `uniqueNames(paths)`, `shortenBranch(branch, max)`. UI는 렌더만 한다.

## ② 공용 호버 툴팁 컴포넌트

- `ui/Tooltip.tsx` — 자식(트리거)을 감싸 마우스오버·포커스 시 카드로 띄운다. 지연 400ms(포커스는 즉시), 이탈·ESC·스크롤·클릭 시 닫힘, `position: fixed` + 화면 밖이면 반대편으로 뒤집기, 마우스를 툴팁 위로 옮겨도 유지되지 않음(정보 전용 — 클릭 대상 없음).
- **접근성**: 트리거에 `aria-describedby`로 연결하고 툴팁 노드는 `role="tooltip"`. 기존 `aria-label`이 있는 트리거는 그대로 둔다(중복 낭독 방지).
- **E2E 가시성**: 트리거에 `data-tooltip="<평문>"`을 남긴다 — 렌더 없이도 문구를 단언할 수 있어 hover 플레이크를 피한다. 리치(다중 줄) 툴팁은 `data-tooltip`에 요약 한 줄만 넣는다.
- **네이티브 `title` 전면 교체(41곳)**: 렌더러의 실제 DOM `title` 속성을 전부 Tooltip으로 옮긴다(컴포넌트 prop인 `title`(Panel·ConfirmDialog 등)은 대상 아님). 교체 후 그 요소에 네이티브 `title`을 남기지 않는다(OS 툴팁 이중 표시 방지).
- **E2E 4곳 전환**: `toHaveAttribute('title', /지금 여기/)`(브랜치 행 3건·워크트리 행 1건)을 `data-tooltip` 기준으로 재작성한다 — 같은 상태를 같은 강도로 단언(비활성·삭제 금지).

## ③ 워크트리 리치 호버 카드

행 전체를 Tooltip으로 감싸 다음을 **잘림 없이** 한 번에 보여준다:

```
feature/DW-1051
/Users/sangyeop_kim/.claude/worktree/goofy-lalande-9418a7/dataworks-frontend
출처 .claude · 브랜치 feature/DW-1051 · HEAD a037b46
main에서 갈라짐 · 12개 앞섬 · 3개 뒤처짐
```

- 경로는 전문(줄바꿈 허용). 분리됨·없어진 폴더·잠김(locked)은 그 상태를 문구로 명시.
- 마지막 줄(분기점)은 ④가 준비되면 채우고, 계산 전/실패면 그 줄만 생략한다(카드 나머지는 즉시 표시).

## ④ 분기점 — 지연 계산·캐시

- 엔진 `worktrees.forkPoint(path)`: 기준 브랜치를 정하고(`origin/HEAD` symref → 없으면 `main` → `master` 중 실존하는 첫 것) `git merge-base <기준> <워크트리 HEAD>` + `rev-list --left-right --count`로 앞섬/뒤처짐을 센다. 기준을 못 정하거나 관계없는 계보면 `null`(카드에서 그 줄 생략).
- **목록 렌더 시에는 부르지 않는다.** 호버가 400ms 유지돼 카드가 뜰 때 그 워크트리 하나만 계산하고, `path + headHash`를 키로 store에 캐시한다(HEAD가 바뀌면 자동 무효).
- 실패는 조용히 무시(에러 배너 없음 — 조회성).

## 에러·엣지

| 상황 | 처리 |
| --- | --- |
| 홈 밖 경로(예: `/Volumes/ext/...`) | `~` 축약 없이 최상위 폴더 이름을 출처 칩으로 |
| 리프 이름이 겹치고 조상까지 전부 같음(불가능하지만 방어) | 전체 경로를 이름으로 표시 |
| 경로가 한 조각(`/repo`) | 축약 없이 그대로 |
| 분리됨(detached) 워크트리 | 1줄 `분리됨 (짧은해시)`, 분기점은 HEAD 해시 기준 계산 |
| 없어진 폴더(prunable) | 기존 흐림·배지 유지, 카드에 "폴더가 없어졌어요" 한 줄 |
| 툴팁이 화면 밖으로 나갈 때 | 반대편으로 뒤집고, 그래도 넘치면 뷰포트 안으로 밀어 넣음 |
| 툴팁 표시 중 목록 갱신(감시) | 트리거가 사라지면 툴팁도 즉시 닫힘 |
| 드래그 영역(E7f 헤더) 위 툴팁 | 헤더 트리거는 no-drag 요소라 기존 규칙 그대로 |

## 테스트

- **순수 단위**: `shortenPath`(홈 축약·뒤 조각 보존·한 조각·홈 밖), `sourceChip`(dot 폴더·홈 직속·홈 밖), `uniqueNames`(겹침 1단·2단 확장·미겹침 유지), `shortenBranch`(앞 생략·짧으면 그대로).
- **컴포넌트 단위**: Tooltip 지연·ESC 닫힘·`aria-describedby` 연결(jsdom).
- **E2E**: ① 같은 이름 워크트리 2개(다른 출처)가 목록에서 서로 구분됨(유일화된 이름·출처 칩) ② 행 호버 시 카드에 전체 경로가 잘림 없이 보임 ③ 기존 `title` 단언 4곳을 `data-tooltip`으로 전환(무회귀) ④ 워크트리·브랜치 기존 E2E 전건 무회귀.
- **스크린샷**: 워크트리 목록(같은 이름 2개 구분 상태)·호버 카드 — 컨트롤러 육안 + 사용자 확인.
- **플랜 사전 실측**: 현재 41개 `title` 사용처 목록화(컴포넌트 prop 제외 확정), `origin/HEAD` symref 존재 여부별 기준 브랜치 결정 실측, jsdom에서 Tooltip 타이머 테스트 관례(E6b `page.clock` 대응물), 두 줄 행이 E7g 워크트리 CSS·가상 스크롤 높이에 주는 영향.
