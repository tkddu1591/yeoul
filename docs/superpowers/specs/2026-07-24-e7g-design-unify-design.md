# E7g — 디자인 정합 설계 (실험 공간 depth 트리·상태 아이콘화·워크트리/터미널 톤 통일)

2026-07-24 브레인스토밍 확정본(시각 컴패니언 3화면). 사용자 원 피드백: "실험 공간·워크트리·터미널 UI가 전부 이질적 — 디자인 톤이 안 맞음. 브랜치는 depth 구조여야 하고, 클릭하면 메뉴가 아니라 선택·조회가 되어야." 확정: v2 3단 인터랙션 / A(상태 아이콘화)·B(워크트리 톤)·C(터미널 톤) / 인라인 컬러 ↑↓(IntelliJ 참고 이미지).

## 공통 원칙

- **하나의 행 언어**: 변경 목록(file-row)이 정본 — 토큰 간격(--space-*)·--radius-sm·hover·선택 하이라이트(--color-selection-bg)를 실험 공간·워크트리 행이 그대로 쓴다. 하드코딩 px 제거.
- **상태는 텍스트 칩이 아니라 아이콘·타이포로**: "지금 여기"·"터미널 대상"류 칩 제거. 의미는 글리프+굵기+색으로, 설명은 title 툴팁으로.
- **동작 변경은 실험 공간 클릭 3단뿐** — 워크트리·터미널의 기존 동작(E7b·E7c·E7d)은 시각만 바꾸고 유지한다.

## ① 실험 공간 — depth 트리

- `/` 세그먼트 기반 **접이식 트리**: 폴더 행(▸/▾ + 이름 + 하위 개수 배지) + 들여쓰기(단계당 고정 인덴트, 다단 중첩 지원). 기존 groupBranches(1단 납작 그룹)를 **트리 빌더 순수 함수로 대체**(branch-groups 확장 — 순수·단위 테스트).
- 접기 상태는 세션 로컬(컴포넌트 상태 — 영속 안 함, YAGNI). 기본 펼침.
- 그룹 대분류("내 공간 (로컬)"/"ORIGIN (원격)")는 유지하되 흐린 캡션 타이포로 통일.
- **검색 중에는 평면 매치 목록**(트리 대신 전체 경로 표시) — 트리 필터링의 복잡도 회피.
- 원격도 같은 트리 규칙(origin/ 아래 폴더 중첩).

## ② 실험 공간 — 3단 인터랙션 (동작 재설계)

- **1클릭 = 선택만**: 중립 하이라이트(--color-selection-bg), 아무 동작 없음. 키보드 포커스와 동일 취급.
- **2클릭(더블클릭) = 조회**: 우측 "저장된 역사"가 **그 브랜치 기준**으로 전환 — 헤더에 "조회 중: <이름> ✕" 알약, 조회 행은 보라 하이라이트. ✕(또는 다른 브랜치 더블클릭 해제/전환)로 전체 그래프(지금 여기 기준) 복귀. 조회 중 커밋 클릭 상세·우클릭 메뉴는 평소대로.
- **우클릭 = 메뉴**: 기존 E7a 메뉴 항목 그대로. **좌클릭에서 메뉴 제거**(현행 좌클릭 openMenu 폐지). 키보드 활성(Enter)은 선택, 메뉴 키(ContextMenu 키)는 메뉴.
- 조회 데이터: 엔진 `history.list`에 **선택적 ref 인자**(`list(limit, ref?)` — ref 있으면 `git log <ref>` 기반·--all 아님). store에 조회 상태(`historyRef: string | null`) — 스냅샷 갱신·감시 갱신에도 조회 유지(E7d ⑤ 원칙), 조회 브랜치가 사라지면 자동 복귀.
- 워크트리·변경 탭 전환과 독립(좌측 탭 이동해도 조회 유지). 브랜치 이동(switch) 등으로 "지금 여기"가 바뀌면 조회는 유지하되 pill이 남는다(✕로 복귀).

## ③ 상태 아이콘화 (A 확정)

- **지금 여기**: 행 글리프를 ⎇ → **보라 ➤**(accent 토큰) + 이름 굵게. "지금 여기" 칩 제거, `title="지금 여기 — 현재 작업 중인 실험 공간"` 툴팁.
- **인라인 컬러 ↑↓ (IntelliJ 참고 이미지 확정)**: 이름 **바로 옆**에 `↑N`(올릴 것 — 성공/초록 계열 토큰)·`↓N`(받을 것 — 경고/주황 계열 토큰), 0인 쪽은 숨김. 우측 끝 회색 배지("동기화됨"·"↑2"·"연결 없음") **전부 제거** — 동기화됨은 무표시(조용), 연결 없음은 흐린 이름 톤 + 툴팁("아직 원격과 연결 안 됨"). 색은 기존 디자인 토큰에서 — 없으면 WCAG 대비 회귀 테스트 대상으로 신설(플랜 실독).
- gone(원격에서 사라진 연결)은 ↑↓ 대신 **흐린 이름 + 툴팁("원격에서 사라진 연결 — 백업하면 다시 만들어져요")** — 연결 없음과 같은 시각 계열, 툴팁 문구로만 구분(정보 손실 없음).

## ④ 워크트리 톤 (B 확정 — 시각만)

- 이모지(🏠/🌳) → 글리프: 본체·"지금 여기" = **➤**(실험 공간과 동일 규칙), 링크드 = ⌂. "터미널 대상" 칩 → 행 우측 **❯_ 글리프**(터미널 아이콘) + 툴팁.
- 2줄 경로 → **이름 옆 한 줄 흐림**(말줄임). 브랜치 배지는 우측 유지(작은 흐린 텍스트).
- 행 언어·간격은 ①과 동일. prunable("없어진 폴더")은 흐림+배지 유지(정보 손실 금지). 클릭·우클릭 동작 무변(E7c).

## ⑤ 터미널 톤 (C 확정 — 시각만)

- 알약 탭 → **밑줄형 탭**(좌측 [변경|실험 공간|워크트리] 탭과 같은 시각 규칙 — 활성 밑줄 accent). ＋·접기·에러 줄 타이포·간격 토큰화. 도크 프레임(E7d 서피스 토큰)·xterm 팔레트(E7d)·동작 전부 무변.

| 검색 중 접기 상태 | 검색 해제 시 이전 접기 상태 복원(컴포넌트 상태 유지) |

| 가상화(수백 브랜치) | E7a 후속 그대로 v1 일반 스크롤 — 트리 접기가 행 수를 줄인다 |

## 테스트

- **순수 단위**: 트리 빌더(다단 중첩·리프/폴더 공존·개수 집계·정렬), ↑↓ 표시 결정(0 숨김·양쪽·연결 없음), 검색 평면화.
- **E2E**: 1클릭=선택만(역사 무변), 더블클릭=조회 전환(다른 브랜치 커밋이 보임)+✕ 복귀, 우클릭 메뉴 동작 유지(기존 E2E의 branch-row 클릭→메뉴 흐름은 **더블클릭/우클릭으로 재작성 필요** — 기존 스위트 영향 조사 플랜 몫), 폴더 접기/펼치기, 워크트리·터미널 기존 E2E 무회귀(시각만 변경).
- **스크린샷**: 실험 공간 트리(조회 중 상태)·워크트리·터미널 각 1장 — 컨트롤러 육안 + 사용자 확인.
- **플랜 사전 실측**: 기존 E2E 중 branch-row 좌클릭 의존 테스트 전수 조사, history.list ref 인자화의 그래프 파서 영향(--all 전제 코드), 토큰(성공/경고 색) 존재 여부, groupBranches 사용처 전수.
