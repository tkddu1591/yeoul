# E12 — 사이드 접기 + 터미널 정체성 설계

2026-07-29 사용자 피드백 3건:
1. "좌측 사이드 우측 사이드 열고 닫기도 되었으면 좋겠어"
2. "터미널 너무 레거시 터미널같이 생겼고 왜 계속 번호는 1, 2, 3 이런식으로 붙는거야? 지워도 계속 붙으니까 이상해"
3. "내가 보고있는 워크트리에서만 쓸 터미널 리스트인데 계속 다른 워크트리에서 쓰는게 붙는것처럼 따라오는것처럼 네이밍이 되어있어"

사용자 선택: 탭 이름은 **그룹 안에서 1부터**, 터미널 외형은 **네 가지 전부**(탭바·글꼴/여백·색/프레임·빈 상태), 사이드는 **버튼 + 단축키**.

## 진단 (실측)

**② 번호가 계속 붙는 원인:** `use-terminal-sessions.ts:45`의 `counterRef`는 **단조 증가하는 전역 카운터**다. 탭을 닫아도 줄지 않고(`:96` `counterRef.current += 1`만 있다), **워크트리 그룹과 무관하게 하나**다. 그래서 3번을 지우고 새로 만들면 4번이 되고, 워크트리 A에서 1·2를 만들면 워크트리 B의 첫 탭이 3번이 된다.

**③ 남의 것이 따라오는 것처럼 보이는 원인:** 탭 제목이 `` `${counterRef.current}: ${options?.label ?? '쉘'}` ``(`:113`)이고 `label`은 **워크트리 이름**이다. 워크트리 B 목록에서 `3: wt-beta`·`4: wt-beta`가 보이는데 — **번호는 1·2가 다른 어딘가에 있다고 암시하고, 라벨은 이미 그 워크트리를 보고 있으므로 중복**이다. 두 요소가 겹쳐 "섞여 있다"는 인상을 만든다. 실제 격리(`groupKey`, E7h ④)는 정상 동작하고 있다 — **보이는 이름만 거짓말을 한다.**

**① 사이드 접기:** 없다. 열 폭은 `ui/column-resize.ts`의 `computeColumns`가 관리하고(중앙 `CENTER_MIN` 380 보장, `MAIN_CHROME` 94), `layout.css:177`이 `grid-template-columns: 380px minmax(0,1fr) 6px 360px`를 초기 폴백으로 둔다.

**터미널 외형 현황:** `new Terminal({ fontSize: 12, theme, scrollback: 1000 })` — **폰트 패밀리·줄간격 미지정**(브라우저 monospace 기본). 도크 본문 패딩 `var(--space-1)` = **4px**. 탭은 `padding: 0 4px 2px` + 2px 밑줄. 빈 터미널에 대한 안내는 **없다**.

## ① 좌·우 사이드 접기

- **버튼**: 각 사이드 패널의 바깥 모서리에 접기 버튼. 접힌 상태에서는 **펼치기 버튼이 그 자리에 남는다**(완전히 사라지면 되돌릴 방법이 화면에 없다).
- **단축키**: `⌘⌥1`(좌) · `⌘⌥2`(우). 기존 `⌘\``(터미널)·`⌘F`(찾기)와 겹치지 않는다.
- **상태 영속**: `settingsApi`에 `leftCollapsed`·`rightCollapsed`. 창을 다시 열어도 유지된다(우측 폭 `rightWidth` 선례와 같은 자리).
- **`computeColumns`가 정본**: 접힘은 새 CSS 분기가 아니라 **폭 계산의 입력**으로 넣는다 — 접힌 열은 폭 0(+리사이저 숨김)이고, 남는 폭은 기존 우선순위(중앙 ≥ 380 → 사용자 우측 폭 → 좌측 기본)를 그대로 따른다. 순수 함수라 단위 테스트로 덮인다.
- **양쪽 다 접으면** 중앙이 전폭이 된다. 막지 않는다 — diff에 집중하는 정당한 상태다.
- 접기/펼치기는 **E11 모션을 타지 않는다**: 열 폭은 인라인 style로 관리되고 레이아웃 속성이라 전환하면 버벅인다(E11 안전망이 금지). 즉시 전환한다.

## ② 터미널 탭 이름

- **번호는 그룹(워크트리) 안에서 1부터**, 닫으면 **빈 번호를 재사용**한다. "지금 이 목록에서 몇 번째"만 뜻하게 만든다.
- **워크트리 라벨을 탭에서 뺀다.** 그 목록 자체가 이미 그 워크트리다. 대신 **도크 헤더에 현재 워크트리를 한 번** 표시한다(지금도 `terminal-dock__hint`가 저장소 이름을 보여준다 — 이 자리를 쓴다).
- 번호 배정은 **순수 함수**로 분리한다(`nextTabNumber(usedNumbers)`) — 재사용 규칙은 단위 테스트로 고정한다.
- 탭 라벨 최종형: `1`·`2`처럼 번호만. 쉘 이름이나 cwd는 **툴팁**으로(E7j Tooltip 재사용).

## ③ 터미널 외형 4종

| 항목 | 지금 | 바꿀 것 |
| --- | --- | --- |
| **탭바** | 2px 밑줄 + `padding: 0 4px 2px`, 닫기 X가 항상 노출 | 알약형 탭(`--radius-control`), 활성은 배경 채움, 닫기 X는 **호버·활성일 때만** 나타난다(항상 보이면 시끄럽다). `+` 버튼은 탭 줄 끝의 고스트 |
| **글꼴·여백** | `fontSize: 12`, 패밀리·줄간격 미지정, 본문 패딩 4px | 코드용 패밀리를 명시(앱의 `--font-mono` 토큰과 일치), `lineHeight: 1.4`, 본문 패딩 `var(--space-3)` 좌우 + `var(--space-2)` 상하 — 글자가 프레임에 붙지 않게 |
| **색·프레임** | `--color-border-strong` 테두리 + `--radius-container` | 패널들과 같은 위계로: 테두리는 `--color-border`, 내부 배경은 xterm 팔레트가 소유하되 **프레임과 팔레트 배경이 같은 톤**이 되도록 팔레트 배경을 서피스 토큰에 맞춘다(E7d ③에서 라이트 모드 검은 띠를 잡은 그 지점) |
| **빈 터미널** | 프롬프트만 깜빡임 | 새 탭 첫 화면에 **한 줄 안내**: 지금 폴더가 어디인지 + 이 터미널이 어느 워크트리 것인지. 셸에 문자를 주입하지 않고 **오버레이로** 띄우고 첫 입력 시 사라진다(셸 히스토리를 오염시키지 않는다) |

## ④ E2E 포커스 테스트 플레이크 (내가 만든 결함)

E9a에서 넣은 `창이 포커스를 받으면…`은 `GIT_GUI_E2E_SHOW=1`로 **실제 창을 띄우고 OS 포커스를 가져간다.** 그래서 다른 Electron 창이 떠 있으면(=사용자가 개발 앱을 쓰는 동안이면) 경합해 흔들린다 — E11 병합 직후 실제로 한 번 실패했다. `toPass` 재시도로 완화했지만 **근본 해결이 아니다.**

**해결:** 검증 대상은 "창이 `focus` 이벤트를 받으면 렌더러가 재조회한다"는 **우리 코드의 계약**이지, "macOS가 우리 창에 포커스를 준다"는 **Electron의 책임**이 아니다. main 프로세스에서 `BrowserWindow`의 `focus` 이벤트를 직접 발생시켜 계약만 검증하고, 실제 창을 띄우지 않는다. 그러면 경합이 원천적으로 사라진다. **바뀌는 것은 자극 방식뿐이고 단언은 그대로다.**

## 에러·엣지

| 상황 | 처리 |

| 양쪽 접힘 + 최소 창(960) | 중앙이 전폭. `CENTER_MIN`보다 커지므로 기존 산식과 충돌 없음 |
| 접힌 상태에서 커밋 클릭(우측에 상세가 뜨는 동작) | 우측을 **자동으로 펼친다** — 결과를 볼 수 없는 곳에 보내는 건 죽은 클릭이다 |

## 테스트

- **순수 단위**: `nextTabNumber` 재사용 규칙(빈 번호 채우기·연속 배정·전부 닫힘), `computeColumns`에 접힘 입력 추가(좌 접힘·우 접힘·양쪽 접힘 × 최소 창) — 기존 11건에 이어 붙인다.
- **E2E**: ① 좌측 접기 버튼으로 접히고 펼쳐진다(폭 실측) ② 단축키로도 된다 ③ 접힌 채 재시작해도 유지된다 ④ 워크트리 A에서 탭 2개를 만들고 워크트리 B로 가면 **B의 첫 탭이 1번**이다 ⑤ 탭을 닫고 새로 만들면 **빈 번호를 재사용**한다.
- **무회귀**: 기존 108건 전건, 특히 E6a 열 폭·E7b 도크·E7h 터미널 그룹.
- **플레이크**: 포커스 테스트를 실제 창 없이 바꾼 뒤 **전체 스위트를 개발 앱이 켜진 상태로** 2회 돌려 흔들리지 않음을 확인한다(지금까지 못 하던 조건이다).
- **스크린샷**: 터미널(탭·빈 상태), 좌측 접힘, 양쪽 접힘.

## 범위 밖 (후속)

터미널 탭 이름 직접 편집, 분할(split) 터미널, 셸 선택 UI, 사이드 접힘 애니메이션, 터미널 검색(⌘F), 스크롤백 설정.
