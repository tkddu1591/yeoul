## 구조

- 새 스타일은 기존 테마 변수를 사용하는 Tailwind 유틸리티로 작성했다. 전역 초기화를 바꾸지 않도록 Preflight를 사용하지 않는다.
- React Compiler를 빌드에 연결했다. 기존 TanStack Virtual 사용 컴포넌트는 컴파일러가 자동 최적화를 건너뛰며 기존 호환성 경고 5개를 유지한다.
- 원시 응답의 변환은 adapter, 작업 정책은 domain/service, IPC는 query와 preload/main, 편집 상태는 hook/store가 맡는다.
- PR 정책은 순수 domain에 두고 GitHub 응답 변환과 한국어 표시 문구를 분리했다.
- 추가 UI는 테마 토큰과 기존 버튼·다이얼로그를 사용한다. 새 패널은 Header·Actions·Body를 명시적으로 구성한다.

## 마무리 보완

- 크래시 전에 실행한 DOM 조회는 렌더러가 정상 재시동돼도 완료되지 않는 경로를 별도 실험으로 재현했다. 크래시 테스트는 강제 종료 전에 새 프로세스의 로드 완료 이벤트를 등록하고, 그 이후에 저장소 UI를 확인하도록 변경했다. 타임아웃을 늘리거나 실패를 무시하지 않는다.
- 수정된 크래시 복구 테스트를 10회 연속 통과했다.
- 빈 안내 행을 건너뛰는 키보드 이동과 Shift 범위 선택을 추가했다.
- 연속 외부 변경과 검색 입력이 중복 IPC 조회를 누적시키지 않도록 조회를 직렬화하고 불필요한 요청을 합쳤다.
- 최근 작업의 저장소 경로와 작업 공간 경로를 함께 저장하고, 이미 열린 대상은 기존 탭을 활성화한다.

## 검증

최종 실행 결과:

- 프로덕션 빌드·타입 검사·React component API 및 domain API 구조 검사 통과.
- 단위 테스트 **1,040개 통과**.
- E2E 전체 **185개 통과**. 크래시 복구를 포함한 전체 실행이 한 번에 통과했다.
- 크래시 복구 테스트는 전체 실행 전에 별도 반복 실행 **10회 연속 통과**했다.
- 린트 오류 없음. 기존 TanStack Virtual 컴파일러 호환성 경고 5개 유지.

- 회귀 E2E: 필터 범위, 대상별 초안, 커밋·외부 변경 반영, 워크트리 대상 유지, 1,500개 파일 가상화, 오래된 커밋 검색, 좌우 줄 스테이징, 부분 실패 재시도, 리뷰 수정 요청, 복제 취소, 표시 선호 저장.
- 기존 E2E: 커밋·동기화·충돌·브랜치·워크트리·터미널·다중 창·탭·복원 흐름.
- 도메인·호스팅 정책 테스트: 최신 리뷰 우선, 이전 head 승인, 취소된 리뷰, 초안·병합 조건, 본문 없는 수정 요청의 보존.
- 타입 검사, 린트, React component API·domain API 보조 검사, 프로덕션 빌드.

실제 GitHub 계정에 댓글·승인·병합을 보내지 않고 로컬 모의 API로 검증한다. 실제 계정의 SSH·SSO·조직 보호 정책 및 VoiceOver 전체 적합성은 별도 환경 검증 대상이다.

통합 활동 목록은 저장소당 50개부터 추가 로드하며 최대 5,000개를 표시한다. 더 오래된 커밋은 검색 또는 현재 저장소 그래프로 탐색한다. 검색은 기존 Git adapter의 최대 50,000개 커밋 스캔 범위에서 동작한다. 본격적인 3-way 충돌 편집기와 앱 내부의 PR 파일별 인라인 리뷰는 기존 제품 로드맵의 별도 확장 범위다.
